Resize Gambar — Word Add-in

Halaman ini adalah landing page add-in Word Anda yang sudah ter-deploy di GitHub Pages.

Halaman ini bukan untuk dipakai langsung. Add-in ini hanya berfungsi jika dimuat di dalam Word Online / Word Desktop melalui manifest.xml. Lihat panduan deploy untuk detail.

File penting

  • taskpane.html — UI panel add-in
  • manifest.xml — definisi add-in (upload ini ke Word)
  • PANDUAN-DEPLOY-GITHUB-PAGES.md — panduan lengkap

Cara pakai

  1. Buka Word Online: office.com/launch/word
  2. Buka dokumen → tab Insert → Add-ins → Upload My Add-in
  3. Upload file manifest.xml
  4. Add-in muncul di tab Home → group Gambar Tools
